# Setup

## Requirements

- WordPress 5.0+
- **AMG Suite** plugin active
- **Yoast SEO** or **All in One SEO** installed (the source for excerpt data)

## Installation

1. Download `amg-excerpts.zip`
2. WordPress Admin → Plugins → Add New → Upload Plugin
3. Activate
4. Find it under **AMG → Excerpts**

## First-time configuration

After activation, go to **AMG → Excerpts → Settings** tab:

1. **Post Types** — Check which types to include (default: Posts and Pages). If you have custom post types with SEO descriptions, check those too.
2. **SEO Source** — Choose Auto-detect (recommended), Yoast only, or AIOSEO only. Auto-detect tries Yoast first, then AIOSEO.
3. Click **Save Settings**

That's it. The plugin is ready to use.
