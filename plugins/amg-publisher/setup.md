# Setup

## Requirements

- WordPress 5.0+
- **AMG Suite** plugin active
- **Enfold theme** or **Elementor** installed (determines which builder is used)
- **Yoast SEO** recommended (for meta title/description)

## Installation

1. Download `amg-publisher.zip`
2. WordPress Admin → Plugins → Add New → Upload Plugin
3. Activate
4. Find it under **AMG → Post Publisher** (or via the `wordable_import` post type in the sidebar)

## No configuration needed

The plugin detects your active theme and builder automatically. Just import content and start building.
