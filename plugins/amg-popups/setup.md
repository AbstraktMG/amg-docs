# Setup

## Requirements

- WordPress 5.0+
- **AMG Suite** plugin active

## Installation

1. Download `amg-popups.zip`
2. WordPress Admin → Plugins → Add New → Upload Plugin
3. Activate
4. Find it under **AMG → Popups**

No additional configuration needed — just start creating popups.
