# Overview

AMG Popups & Sticky Bars creates targeted popups and sticky notification bars with custom triggers, timing, and display rules.

## What it does

- **Popups** — centered modal overlays with customizable content, styling, and animations
- **Sticky Bars** — fixed top/bottom notification bars that stay on screen
- **5 trigger types** — button click, exit intent, timed delay, scroll depth, inactivity
- **Targeting** — display on specific pages, post types, or site-wide
- **Cookie control** — prevent repeat display for a set duration (1 day to 1 year)
- **WYSIWYG editor** — full WordPress editor for popup/bar content

## Trigger types

| Trigger | How it fires |
|---------|-------------|
| Button Click | User clicks a specific HTML element (by ID) |
| Exit Intent | Mouse leaves top of viewport (user about to leave) |
| Timed Delay | After X milliseconds (e.g., 5 seconds after page load) |
| Scroll Depth | When user scrolls past X% of the page |
| Inactivity | After X seconds of no mouse/keyboard/touch activity |

## Popup vs Sticky Bar

| Feature | Popup | Sticky Bar |
|---------|-------|------------|
| Overlay/backdrop | Yes | No |
| Position | Center, corners | Top or bottom |
| Animations | Fade, slide from any direction | Fade, slide, spread |
| Available triggers | All 5 | Exit intent + timed delay only |
| Logo support | No | Yes (left or right) |
| Text alignment | No | Left, center, right |
