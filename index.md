# AMG Suite Documentation

A unified collection of WordPress tools built for the Abstrakt Marketing Group content team.

## What is AMG Suite?

AMG Suite is a master plugin that brings together purpose-built tools under a single admin menu. Instead of juggling separate plugins with scattered menus and settings pages, everything lives under one roof — a single **AMG** menu in your sidebar.

## Plugins

| Plugin | What it does |
|--------|--------------|
| [AMG Suite](plugins/amg-suite/) | Master dashboard, remote config, version management |
| [GDocs Importer](plugins/amg-gdocs-importer/) | Pull Google Docs into WordPress as draft posts |
| [Post Publisher](plugins/amg-publisher/) | Build blog layouts from imported content |
| [Post Migration](plugins/amg-post-transfer/) | Export and import posts between WordPress sites |
| [Excerpts](plugins/amg-excerpts/) | Sync SEO meta descriptions to WordPress excerpts |
| [Post Repairer](plugins/amg-post-repairer/) | Fix broken formatting and metadata issues |
| [Media Cleaner](plugins/amg-media-cleaner/) | Find and remove unused media files |
| [Popups & Sticky Bars](plugins/amg-popups/) | Create targeted popups and sticky bars |
